Universal Interest Indicatrix: LLM-Friendly Procedure
Objective
Construct a principled “line of maximum shared interest” for a group of individuals/entities based on their search terms, content, or topic vectors. Map arbitrary inputs into this shared-interest space.
⸻
Step 1: Define Topic Axes 1. Collect semantic clusters representing relevant topics. • Example axes: cosmology, emergence, transhumanism, anomalies, science communication. 2. For LLM-only usage: • Ask the LLM to extract keywords or clusters from a set of documents, posts, or transcripts. • Optionally, use embedding-based similarity to merge overlapping topics.
Extension: With embeddings or numeric tools, define these axes in vector space and normalize to a unit hypersphere.
⸻
Step 2: Encode Individuals’ Interests 1. For each individual/entity: • Compile search terms, transcripts, posts, or documents. • Convert each piece into a vector along the topic axes. • LLM-only: assign weights via frequency, relevance, or confidence. • Numeric extension: use embeddings to create actual vectors in \mathbb{R}^d. 2. Represent as a table: • Rows = topic axes • Columns = individuals • Cells = weight / score / relevance of the individual along that topic
⸻
Step 3: Compute Centroid • The centroid of all individual vectors defines the mean interest vector:
\mu^\mu = \frac{1}{N} \sum_i X_i^\mu • LLM-only: can be computed symbolically as “average score per topic”. • Extension: numeric computation for precise vector centroid.
⸻
Step 4: Define Candidate Line (Principal Direction) • Line equation:
\ell(t) = \mu + t v • Where v is a unit vector representing the direction of maximum shared interest. • LLM-only approach: • Approximate v as the topic axis with highest summed weight across all individuals, or a weighted combination of top axes. • Numeric / embedding extension: • Compute principal eigenvector of the covariance matrix of centered topic vectors (PCA-style).
⸻
Step 5: Measure Alignment (Interest Lagrangian) 1. For each individual, define “misalignment” energy with respect to the line:
\mathcal{L}i = \sum\mu (X_i^\mu - (\mu^\mu + ((X_i-\mu)\cdot v) v^\mu))^2 • LLM-only: approximate by comparing per-topic deviations from the projected “line-weighted topic profile”. • Numeric extension: compute squared perpendicular distance in vector space.
2.	Total action:
S = \sum_i \mathcal{L}_i • Minimizing S → optimal line of shared interest.
⸻
Step 6: Project Entities onto Line • Compute each entity’s scalar projection along the line:
p_i = (X_i - \mu) \cdot v • Use this to generate a mapped table aligned with the line of maximum interest: • LLM-only: assign scores or ranks along the combined top axes. • Numeric: reconstruct projected vectors along the line.
⸻
Step 7: Map Arbitrary Inputs • Any new input (table, embeddings, search terms) can be projected into the same line: 1. Encode new input into topic vector X_\text{new} 2. Subtract the centroid: X_\text{new} - \mu 3. Compute projection along principal line:
p_\text{new} = (X_\text{new} - \mu) \cdot v • Output: • Scalar score along the principal interest line • Reconstructed vector for aligned table representation
⸻
Step 8: Optional Extensions • Time-evolving interest trajectories: parameterize inputs over \lambda \in [0,1] and include derivative terms in the Lagrangian to measure topic drift. • Higher-order interactions: include second derivatives or torsion to capture non-linear topic combinations. • Dynamic updates: as new individuals or topics are added, recompute centroid and principal line. • Embedding-based similarity: replace symbolic weighting with numeric embeddings for higher precision. • Visualization: 2D/3D projection of the interest line and entity projections for exploratory analysis.

Step 9: Summary of Workflow 1. Define topic axes from corpus or domain knowledge. 2. Encode each individual as a topic vector (table). 3. Compute centroid of all vectors. 4. Determine principal direction (line of maximum interest). 5. Evaluate alignment via the interest Lagrangian. 6. Project individuals along the line → mapped table or scores. 7. ⸻ III. A Python implementation of a “Universal Interest Indicatrix” based on the Lagrangian framework we discussed. It’s fully generic: it can ingest a table, embeddings, TF-IDF vectors, or any numeric representation of topics and individuals.

import numpy as np
class UniversalInterestIndicatrix: def init(self, topic_vectors, alpha=0.0, beta=0.0): """ topic_vectors: numpy array of shape (num_topics, num_entities) Each column represents an entity; each row a topic axis alpha: weight for first derivative (rate of interest change) beta: weight for second derivative (curvature / torsion) """ self.X = topic_vectors self.alpha = alpha self.beta = beta self.num_topics, self.num_entities = self.X.shape self.mu = np.mean(self.X, axis=1, keepdims=True) # centroid vector
def center_vectors(self):
    """Center vectors around the mean (like PCA preprocessing)"""
    return self.X - self.mu

def principal_line(self):
    """
    Computes the line of maximum shared interest using the
    Lagrangian minimization (equivalent to PCA first component)
    Returns:
        v: unit vector along principal interest direction
        mu: centroid point
    """
    Y = self.center_vectors()
    # covariance matrix
    C = Y @ Y.T
    # principal eigenvector
    eigvals, eigvecs = np.linalg.eigh(C)
    v = eigvecs[:, -1]  # largest eigenvalue
    v /= np.linalg.norm(v)
    return v, self.mu

def project_onto_line(self, v):
    """
    Project all entities onto the principal line
    Returns:
        projections: scalar values along the line
    """
    Y = self.center_vectors()
    projections = (v.T @ Y)
    return projections

def generate_mapped_table(self):
    """
    Returns a new table of entities projected along the principal line,
    which can be treated as a "line-of-interest aligned table"
    """
    v, mu = self.principal_line()
    proj = self.project_onto_line(v)
    # reconstruct vectors along the line
    mapped = mu + v[:, None] * proj
    return mapped

def action_lagrangian(self, v):
    """
    Compute the total 'interest action' along the candidate line
    S = sum_i ||x_i - projection_on_line||^2 + optional derivative terms
    """
    Y = self.center_vectors()
    S = 0.0
    for i in range(self.num_entities):
        xi = Y[:, i]
        projection = (xi @ v) * v
        dist_sq = np.sum((xi - projection) ** 2)
        S += dist_sq
    return S

def arbitrary_input_mapping(self, X_new):
    """
    Map any new set of topic vectors to the same principal line
    Returns projected coordinates along the original line
    """
    v, mu = self.principal_line()
    X_new_centered = X_new - mu
    projections = (v.T @ X_new_centered)
    mapped = mu + v[:, None] * projections
    return mapped, projections
