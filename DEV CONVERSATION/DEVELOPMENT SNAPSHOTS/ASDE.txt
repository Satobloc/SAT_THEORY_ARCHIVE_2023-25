
SAT_4D — PREDICTIONS & RETRODICTIONS (WITH TOLERANCES)
======================================================

Scope
-----
This document collates testable claims SAT_4D makes or targets, split into RETRODICTIONS (must already match data) and PREDICTIONS (new/clarified outcomes). Each item carries a tolerance class:

  • Class A (Exact/Structural): Pass/Fail (no deviation allowed).
  • Class B (Quantitative Band): Dimensionless or scale ratios with target error bands (typically 5–10%; specify per item).
  • Class C (Bounded/Directional): Must agree with existing experimental bounds or inequality/direction; any violation falsifies.

Notes
-----
• “Quark-level” refers to partonic bound states (pre-nuclear). 
• All tolerances are framed for post-redevelopment SAT_4D; items marked [Pending derivation] require completion in O1–O6 workflow.
• Where numbers are not yet derived internally, Class C ties the claim to “no violation of current bounds”.
