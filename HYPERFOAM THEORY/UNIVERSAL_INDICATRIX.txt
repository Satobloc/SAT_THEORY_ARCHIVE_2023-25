Define the observable coordinate as:

where e₁ is a chosen direction in ℝ³.

Dynamics

Assume the only dynamical variable is θ(t), and postulate a quadratic “rotational energy”:

L = (1/2)I (dθ/dt)² − (1/2)K θ².

This is formally analogous to a torsional oscillator. The Euler–Lagrange equation yields:

I d²θ/dt² + K θ = 0.

Small-angle approximation

For small θ, expand:

R(t) ≈ I + θ(t)A.

Then:

p(t) ≈ p₀ + θ(t)A p₀.

Thus:

x(t) ≈ x₀ + θ(t)(e₁ · π(A p₀)).

Let C = e₁ · π(A p₀), assumed constant. Then:

x(t) − x₀ ≈ C θ(t).

Substituting θ dynamics:

d²x/dt² ≈ C d²θ/dt² = −(K/I) C θ(t) = −(K/I)(x(t) − x₀).

Therefore:

d²x/dt² + (K/I)(x − x₀) = 0.

This reproduces the harmonic oscillator equation with effective frequency:

ω² = K/I.
