# Nathan Words Extraction

This folder is the intended home for human-readable extracted text.

Readable extraction files should use this pattern:

- 000_EXTRACTED_NATHAN_WORDS_PART_000.txt
- 001_EXTRACTED_NATHAN_WORDS_PART_001.txt
- 002_EXTRACTED_NATHAN_WORDS_PART_002.txt

Logs, indexes, warnings, and machine-readable files should live in:

- ⚒️_extraction_logs_and_indexes/

This placeholder exists so the folder sorts visibly near the top before the next extraction run rewrites live status.
