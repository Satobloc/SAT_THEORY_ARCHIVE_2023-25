RESOURCES

Pointers and reusable generated resources.

Primary locations:
- README.md : public front page and essential context for new archive visitors.
- ..[🎛️_NATHAN_DASH]/ : human-facing dashboard/control folder.
- .[⚙️_AI_FILES]/ : AI/tooling/institutional memory.

Staging / request infrastructure:
- .[⚙️_AI_FILES]/REQUESTS/archive_admin_task.txt — primary AI-side Archive Admin request file for bounded repo-side tasks.
- .[⚙️_AI_FILES]/CONFIG/ — reusable tool configuration files.
- Planned: .[⚙️_AI_FILES]/STAGING/ — staged editing/request buffer for large multi-part resources and workflow requests.

Current operating standard:
- Request-file commits are the default trigger path for routine bounded archive operations.
- Archive Admin is the default assistant-triggerable runner.
- Manual workflow_dispatch is fallback/debug where an automatic or request-driven route exists.
- Full structural indexing is a deliberate exception: `.github/workflows/full-archive-index.yml` runs automatically Monday/Wednesday/Friday and remains manually dispatchable.
- Generated outputs should be committed with logs.
- Workflow-generated commits should use the appropriate loop guard unless a downstream maintenance workflow is intentionally meant to run.

Tool standard:
Every durable archive tool should have:
- script: .[⚙️_AI_FILES]/TOOLS/<tool>.py
- request/config file: .[⚙️_AI_FILES]/REQUESTS/ or .[⚙️_AI_FILES]/CONFIG/
- logs: .[⚙️_AI_FILES]/LOGS/<tool>/ or another explicit task log location
- Archive Admin task mode or workflow wrapper
- committed outputs or committed audit logs

Navigation / indexing note:
- Direct GitHub connector fetches work well for known paths inside .[⚙️_AI_FILES]/, including emoji/bracketed filenames.
- Search can find key files but should not be treated as a complete folder index.
- For reliable AI navigation, maintain explicit indexes and welcome documents.
- The Dashboard archive index is now a sharded-history router, not a monolithic append ledger.

Recommended starting read:
- README.md should be treated as essential front-page context for new archive visitors before deep folder analysis. Read it alongside .[⚙️_AI_FILES]/🪧_WAYFINDING.txt and ORIENTATION.txt.
