### 2. Fundamental-measure hierarchy

The conversation next compresses the canonical state to a single core value `P`, whose default meaning is a canonical decomposition into expansion + rotation. Departures are represented first as three residual classes:

- `ΔH`: departure from the standard coupled helical/rotation-expansion relation;
- `ΔA`: departure from canonical symmetry/isotropy;
- `ΔB`: signed distance from a bifurcation surface/condition.

A representative limiting definition is:

`ΔB = b - b_crit`

with negative/zero/positive values distinguishing pre-critical, critical, and post-critical regimes.

The suggested helical residual is relational rather than two independent rotation/expansion offsets:

`ΔH = H(θ,E) - H_std`

or, if the standard relation is `θ = f(E)`,

`ΔH = θ - f(E)`.

Nathan then explicitly states that these three residuals themselves have a canonical relationship and are an even/canonical decomposition of one higher-order deviation variable. The assistant formalizes the bookkeeping as

`Δ -> (ΔH, ΔA, ΔB)`

with the warning that `1:1:1` is only a schematic placeholder until the actual geometry determines the relation.
