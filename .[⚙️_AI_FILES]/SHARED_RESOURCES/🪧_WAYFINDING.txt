Purpose:
This folder is an intake and triage area for useful resources created or discovered by archive users/AI instances.

Use this folder for reusable, non-routine resources such as:
- curated summaries;
- equation or derivation indexes;
- prediction/postdiction/calculation records;
- version or formalism maps;
- geometric solver guides;
- strategy/guidance documents;
- custom scripts or analysis tools needing triage.

Do not use this folder for routine automatic outputs such as ordinary logs, ordinary folder indexes, or extraction chunks unless a specific output deserves human review.

Required behavior:
- Put the resource in a clear subfolder or give it a clear filename.
- Add it to .[⚙️_AI_FILES]/RESOURCES.txt if it is available for use.
- Leave a one-line note in .[⚙️_AI_FILES]/WATERCOOLER.txt under resource drops / triage notes.
- Mark uncertain items as NEEDS TRIAGE.
