🪧 WAYFINDING — LOGS

STATUS: STUB / NEEDS REVIEW

Purpose:
This folder contains tool, workflow, indexing, extraction, and error logs generated by archive infrastructure.

Use this folder to answer:
- Did a workflow/tool run?
- What did it do?
- What failed?
- Where were outputs written?
- Did anything get skipped, refused, or truncated?

Important subfolders:
- archive_admin/ — detailed Archive Admin run logs.
- workflows/ — stable last-run summaries for workflows.
- folder_indexer/ — folder indexer run details, including skipped items.
- errors/ — visible error reports and histories.

Guidance:
- Logs are evidence, not source theory documents.
- Do not treat generated logs as canonical theory claims.
- If a log reveals a reusable lesson, record it in ..[🎛️_NATHAN_DASH]/⚙️_LESSONS_LEARNED.txt.
- If a log reveals a significant resource, catalog it in .[⚙️_AI_FILES]/RESOURCES.txt and leave a one-line Watercooler note.

Visitor request:
If you diagnose a recurring failure mode, update the relevant Lessons Learned entry and improve the tool/workflow if possible.
