CORE TAXONOMY

SAT ARTIFACTS
- Primary or derived SAT-content documents.
- Examples: theory drafts, PDFs, equations, derivations, predictions, experimental proposals, curated SAT compilations.

ARTIFACT CATALOGS
- Maps to SAT artifacts.
- Examples: ..folder_summary.txt, bibliographic notes, equation indexes, prediction indexes, version indexes, metadata notes.

ARCHIVE MACHINERY
- Tools that help find, preserve, stage, describe, or navigate the archive.
- Examples: Archive Admin, indexers, request files, logs, templates, staging buffers, wayfinding, orientation docs.

See SHARED_RESOURCES/ARCHIVE_TAXONOMY.txt for the canonical short taxonomy.

DOCUMENT ROLES

ORIENTATION.txt
- Core norms and operating principles.
- Explains chunk-awareness, local vs global understanding, staging, indexing, and archive taxonomy.

RESOURCES.txt
- Durable catalog of reusable resources.
- Put stable guides, templates, tools, indexes, maps, and repeated lessons here.

WATERCOOLER.txt
- Informal bulletin board.
- Tips, warnings, temporary discoveries, suggestions, and current working notes.

GUESTBOOK.txt
- Voluntary visitor/handoff context.
- Not mandatory; tool logs and generated indexes carry operational provenance.

SAT_THEORY_ROADMAP_AND_NEEDS.txt
- Theory-development framing and open needs.
- Use for SAT work priorities, not routine archive operations.

SHARED_RESOURCES/
- Reusable institutional references.
- Current important files include:
  - ARCHIVE_TAXONOMY.txt
  - ARCHIVE_ADMIN_TASKS.md
  - FOLDER_SUMMARY_TEMPLATE.txt
  - README.txt

STAGING/
- Holding area for large, fragile, chunked, or unfinished material.
- Use before committing final resources, long requests, or assembled reports.
- Basic flow: INBOX → PARTS → READY → RUNNING → DONE / FAILED.

REQUESTS/
- AI-side request files for Archive Admin and future workflow tools.
- Prefer this for bulky machine-oriented operations rather than cluttering Nathan's dashboard.

TOOLS/
- Source code for archive machinery.
- Tools should log their work and gently point users back to orientation/resources where helpful.

WORKFLOWS/
- Workflow-facing notes and control context.

LOGS/
- Tool and workflow logs.
- Logs record what happened; summaries/catalog notes explain what it means.

CURSORS/
- Reserved for progress cursors, resume points, and future long-running archive processes.

_MIGRATION_HOLD/
- Older/relocated automation files preserved for provenance.
- Do not treat as current machinery unless confirmed.

Breadcrumb conventions

..findex.txt
- Generated structure inventory.
- Says what files/folders exist.
- Does not interpret meaning.

..folder_summary.txt
- Human/AI wayfinding note for a folder.
- Says what the folder appears to mean.
- Should state coverage limits and avoid globalizing from partial reads.

Bibliographic packet notes
- Describe groups of SAT artifacts.
- Should be neutral, provenance-aware, and descriptive before evaluative.

Tool logs
- Record tool actions, targets, warnings, and generated files.
- Use logs to discover recent activity, then inspect artifacts/catalogs for interpretation.

KNOWLEDGE TYPES

1. Archive Knowledge
   What exists in the archive.

2. Theory Knowledge
   What SAT documents claim, derive, predict, or explore.

3. Process Knowledge
   How people and tools work on SAT and the archive.

4. Institutional Knowledge
   How this archive teaches future visitors to navigate itself.
