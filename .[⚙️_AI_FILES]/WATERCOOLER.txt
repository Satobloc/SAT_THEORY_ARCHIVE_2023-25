2026-06-07 — Archive Admin auto-run norm

Preferred request-tool pattern:

ChatGPT updates a small request file
→ GitHub push triggers Archive Admin automatically
→ Archive Admin performs bounded, allowlisted work
→ Archive Admin writes logs/results
→ ChatGPT verifies logs and output

Manual workflow_dispatch remains available as a fallback, but should not be the default for routine request-file operations.

Loop protection: workflow commits by github-actions[bot] should be ignored by the workflow job guard.

This keeps Nathan out of repetitive button-clicking while preserving a clear authorization/audit trail through commits and logs.

2026-06-07 — Legacy workflow path-filter failure

Diagnosis:
The recurring "invalid paths patterns" error came from the old index_folder.yml workflow, not from Archive Admin and not from duplicate-ish filenames.

Root cause:
GitHub Actions push.paths entries are glob patterns. Literal folder names containing square brackets, emoji, and stale dashboard names can break parsing or become fragile.

Norm:
Do not use push.paths filters for bracketed/emoji control folders.

Preferred options:
1. Put trigger/request files under plain ASCII paths, or
2. use broad push triggers with a github-actions[bot] loop guard, or
3. keep legacy workflows manual-only/disabled and route routine work through Archive Admin.

Also:
Similar filenames are confusing and should be cleaned up, but they are not the same problem as invalid workflow path globbing.

2026-06-07 — Control-folder naming and index hygiene

Official control-folder naming convention:

.[...]   AI/tool/admin/control layer
..[...]  Nathan-facing dashboard/control layer

Default indexer behavior should skip:
- folders beginning .[
- folders beginning ..[
- files named ..findex.txt
- .git
- __pycache__

However, skipped items must be logged. Unknown .[...] or ..[...] folders should be flagged as possible control-name collisions, because older archive material might accidentally use the same pattern.

The goal is clean source indexes without silently hiding potentially meaningful material.
